# NLS Maps — Noqtrnl Logic Systems

Personal iPhone map app. Monochrome, Y2K, minimal.

**Phase 1 (now):** pipeline test — background GPS + Dynamic Island.

## Get the latest build
On your iPhone, open:
https://github.com/h33r4n/nls-maps/releases/latest/download/NLSMaps.ipa

Then: LocalDevVPN on → SideStore → **+** → pick `NLSMaps.ipa`.

Every push to `main` builds a new version automatically (GitHub Actions → "Build iPhone app").
